一、环境准备（需要安装的软件）
===============================================================

请依次安装以下软件：

【1】Node.js 18 或以上版本（后端方式一必需）
    下载地址：https://nodejs.org/zh-cn/download
    安装步骤：
      1. 打开下载的安装包
      2. 一路 Next，全部默认即可（会自动添加到 PATH）
      3. 安装完成
    验证安装：
      打开 CMD（按 Win+R，输入 cmd，回车），输入：
        node --version
      如果显示 v18.x.x 或更高版本号，说明安装成功

【2】Java JDK 8（后端方式二必需，如果使用 Node.js 后端可跳过）
    下载地址：https://www.oracle.com/java/technologies/javase/javase8-archive-downloads.html
    或使用 OpenJDK：https://adoptium.net/
    安装步骤：
      1. 下载 JDK 8 Windows x64 安装包
      2. 运行安装程序，记住安装路径（如 C:\Java\jdk1.8.0_xxx）
      3. 配置环境变量：
         右键此电脑 → 属性 → 高级系统设置 → 环境变量
         新建 JAVA_HOME = C:\Java\jdk1.8.0_xxx（你的安装路径）
         在 Path 中添加 %JAVA_HOME%\bin
    验证安装：
      打开 CMD，输入：java -version

【3】Maven 3.6+（后端方式二必需，如果使用 Node.js 后端可跳过）
    下载地址：https://maven.apache.org/download.cgi
    安装步骤：
      1. 下载 Binary zip archive
      2. 解压到 C:\maven（或其他目录）
      3. 配置环境变量：在 Path 中添加 C:\maven\bin
    验证安装：
      打开 CMD，输入：mvn --version

【4】MySQL 8.0
    下载地址：https://dev.mysql.com/downloads/installer/
    安装步骤：
      1. 下载 MySQL Installer（选择较大的完整版）
      2. 运行安装程序，选择 "Developer Default"
      3. 一路 Next，到设置密码页面时：
         ★★ 设置 root 密码为：root ★★
         （项目默认配置就是这个密码，如果设置其他密码需要改配置文件）
      4. 完成安装
    验证安装：
      打开 CMD，输入：mysql -u root -p
      输入密码 root，如果进入了 mysql> 提示符，说明安装成功
      输入 exit 退出

【5】HBuilderX（前端开发工具）
    下载地址：https://www.dcloud.io/hbuilderx.html
    安装步骤：
      1. 下载 HBuilderX 标准版 或 App开发版
      2. 解压到任意目录即可使用（免安装）
      3. 双击 HBuilderX.exe 启动

【6】微信开发者工具
    下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
    安装步骤：
      1. 选择 "稳定版 Windows 64" 下载
      2. 双击安装，一路默认即可
      3. 安装完成后打开，用微信扫码登录

【7】IntelliJ IDEA（后端方式二的 IDE，可选）
    下载地址：https://www.jetbrains.com/idea/download/
    选择 Community（社区免费版）即可

===============================================================
二、MySQL 数据库配置
===============================================================

数据库会在初始化脚本中自动创建，无需手动建库。
只需确保 MySQL 服务正在运行即可。

检查 MySQL 是否在运行：
  方法一：打开 CMD，输入 mysql -u root -p，输入密码 root
  方法二：在 Windows 服务中查看 MySQL 服务状态

如果 MySQL 密码不是 root，需要修改：
  Node.js 后端：修改 backend\config\db.js 中的 password
  Java 后端：修改 backend-java\src\main\resources\application.yml 中的 password

===============================================================
三、后端部署
===============================================================

★★ 两种后端任选其一，推荐方式一（更简单）★★

方式一：Node.js 后端（推荐，简单快速）
--------------------------------------------------------------

【步骤 1】安装依赖
  打开 CMD，切换到 backend 目录：
    cd 你的项目路径\backend
  安装 Node.js 依赖包：
    npm install
  等待安装完成

【步骤 2】初始化数据库
  在 backend 目录下运行：
    node initdb.js
  成功后显示：Database initialized successfully!

【步骤 3】启动后端
  node app.js
  成功后显示：Backend server running at http://localhost:3900

  ★ 后端默认运行在 3900 端口

  ★★ 验证后端是否正常 ★★
  打开浏览器，访问：http://localhost:3900/api/common/leaderboard
  如果看到 JSON 数据，说明后端运行成功

使用 IDEA 运行 Node.js 后端：
  1. 打开 IDEA → File → Open → 选择 backend 文件夹
  2. 打开 Terminal 面板 → 运行 npm install
  3. 右键 app.js → Run 'app.js'


方式二：Java SSM 后端（Spring Boot + MyBatis）
--------------------------------------------------------------

【步骤 1】用 IDEA 打开项目
  1. 打开 IntelliJ IDEA
  2. File → Open → 选择 backend-java 文件夹
  3. IDEA 会自动检测 pom.xml 并下载 Maven 依赖（需要等待）

【步骤 2】确保数据库已初始化
  先用 Node.js 方式初始化数据库（只需运行一次）：
    cd backend
    npm install
    node initdb.js

【步骤 3】运行 Spring Boot
  方法 A — IDEA 中运行：
    找到 src/main/java/com/habit/HabitApplication.java
    右键 → Run 'HabitApplication'

  方法 B — 命令行运行：
    cd backend-java
    mvn spring-boot:run

  启动成功后显示：
    习惯自律养成系统后端启动成功!
    http://localhost:3900

===============================================================
四、前端（UNI-APP 小程序）部署
===============================================================

【步骤 1】HBuilderX 导入项目
  1. 打开 HBuilderX
  2. 文件 → 打开目录 → 选择 frontend 文件夹
     ★★ 注意：是 frontend 文件夹，不是项目根目录 ★★

【步骤 2】配置微信开发者工具路径
  1. 在 HBuilderX 中，点击 工具 → 设置
  2. 左侧选择 "运行配置"
  3. 找到 "微信开发者工具路径"，填入你的安装路径
     通常是：C:\Program Files (x86)\Tencent\微信web开发者工具

【步骤 3】运行到微信小程序模拟器
  1. 点击菜单 运行 → 运行到小程序模拟器 → 微信开发者工具
  2. 等待编译完成，微信开发者工具会自动打开
  3. 如果提示 AppID 不合法，在微信开发者工具中改用 "测试号"

【步骤 4】或运行到浏览器（H5模式预览）
  1. 点击菜单 运行 → 运行到浏览器 → Chrome
  2. 浏览器会自动打开小程序的 H5 版本

★★ 确保后端已经在运行（第三步），否则前端无法加载数据 ★★

七、常见问题排查
===============================================================

问题 1：npm install 失败
  解决：Node.js 没有安装或版本过低
  方案：安装 Node.js 18+，确保 node --version 能正常显示版本

问题 2：node initdb.js 报错 "Can't connect to MySQL server"
  解决：MySQL 没有启动
  方案：在 Windows 服务中启动 MySQL 服务

问题 3：node initdb.js 报错 "Access denied"
  解决：MySQL 密码不是 root
  方案：修改 backend\config\db.js 中的 password 字段

问题 4：小程序模拟器显示空白 / 数据加载失败
  解决：后端没有启动
  方案：先启动后端（node app.js），再启动前端

问题 5：HBuilderX 运行到小程序模拟器失败
  可能原因：
  a) 没有安装微信开发者工具 → 安装后配置路径
  b) 微信开发者工具路径配置错误 → 检查 HBuilderX 运行配置
  c) AppID 不合法 → 在微信开发者工具中选择"测试号"

问题 6：前端报 "网络异常"
  解决：
  a) 确保后端正在运行
  b) 确保后端运行在 3900 端口
  c) 在微信开发者工具中勾选"不校验合法域名"
     （详情 → 本地设置 → 勾选）

问题 7：Java 后端启动失败 "Maven 依赖下载失败"
  解决：配置 Maven 国内镜像
  在 Maven 的 settings.xml 中添加阿里云镜像：
  <mirror>
    <id>aliyun</id>
    <mirrorOf>central</mirrorOf>
    <url>https://maven.aliyun.com/repository/central</url>
  </mirror>
